# 二、第一阶段之后如何继续加深
## 2.1 增加持续输入来源
connectto 可以在用户授权下接入更多日历、任务、邮件、沟通工具、职业资料和录音设备，使人物变化、当前事项、承诺与行动结果更及时地进入同一关系上下文。新增来源继续保留作者、时间、适用范围和披露边界。
## 2.2 扩大可授权的行动范围
第一阶段之后，Agent 可以在三档授权框架下增加更多渠道和行动类型，例如准备材料、协调时间、推进已确认事项和过滤低价值请求。新的个人判断、扩大披露和重要承诺仍需按照用户边界交还本人；系统不得自行提高授权等级。
## 2.3 让临时参与变成长期协作
未注册参与者可以继续通过单次 Connection 获得价值。本人注册并完成身份确认后，可以选择把临时 Connector 中的记录并入长期 Connector，在新的连接者和场景中复用自己拥有的身份、意图与披露边界。
## 2.4 进入 Agent 协作与协商
个人 Agent 可以与其他个人、企业、机构和服务 Agent 交换各方允许使用的最小身份、意图、条件与权限，完成发现、介绍、协调和低风险协商。谁促成连接、各方采取了什么行动以及结果如何，继续回到相关个人拥有的上下文。
# 三、始终保持的产品规则
- 单个用户可以独立获得价值，不以对方安装 connectto 为前提。
- 每位参与者拥有自己的私密上下文和 Connector；临时参与不自动创建平台账户。
- 每条事实、判断、条件和承诺都有明确的可见对象、允许用途和授权状态。
- Connector 只交换各方允许用于当前 Connection 的最小上下文，不建立需要共同维护的统一共享层。
- 用户可以设置、调整、降级、暂停和撤销授权；系统不得自行提高授权等级。
- 未经允许的私人信息、法律或财务承诺、代表本人的价值判断和超出指定范围的联系始终受限。
- 每次行动保留对象、原因、披露内容、对方回应和下一步记录。
- 接受、拒绝、交流、承诺与现实结果都回到人物理解和后续判断。
