# 一、第一阶段已经提供什么

| 能力 | 第一阶段的完整结果 |
| --- | --- |
| 输入与理解 | 文字、语音、会后口述和外部录音进入同一链路；系统识别主要人物、人物线索、承诺、Open Loops 和 Profile 更新 |
| 人物与关系 | 自我 Profile、Living Profile、关系记忆、来源和历史变化持续更新，用户可以查看与修正 |
| 当前事项 | 用户表达正在寻找、推进或能够提供什么，并以此检索人物、继续关系或发起连接 |
| Connector | 响应用户明确意图，并在证据充分时主动提出连接或复联机会，解释双方价值、时机、可信路径和许可条件 |
| Connection | 支持场景化自我介绍、第三方介绍和复联，经必要许可后分享，并帮助真实交流在现有工具中开始 |
| 结果回流 | 用户的采纳、修改、忽略、接受、拒绝和实际结果更新人物、关系、Open Loops 与后续 Connector 判断 |

这些能力从第一次使用开始共同存在，深度随可信上下文和真实结果增加。上下文不足时，Connector 减少主动建议，但相应能力仍属于第一阶段。

# 二、第一阶段之后如何继续加深

## 2.1 增加持续输入来源

connectto 可以在用户授权下接入更多日历、任务、邮件、沟通工具、职业资料和录音设备，使人物变化、当前事项、承诺与行动结果更及时地进入同一关系上下文。新增来源继续保留作者、时间、适用范围和披露边界。

## 2.2 承担更多低风险行动

当人物理解、触发条件和权限边界足够可靠时，Agent 可以逐渐承担恢复上下文、准备消息与材料、协调时间、推进用户已经确认的事项，以及过滤低价值请求。关系建立、第三方介绍、敏感披露和重要承诺继续由本人决定；所有行动可查看、可撤销并保留结果。

## 2.3 扩展跨个人协作

当单人产品持续产生价值，个人可以在不同连接者和场景中复用自己拥有的身份、当前意图与披露边界。每次使用仍按具体对象和目的授权，私人关系上下文不会因复用而公开。

## 2.4 进入 Agent 协作与协商

个人 Agent 可以与其他个人、企业、机构和服务 Agent 交换必要身份、意图、条件与权限，完成发现、介绍、协调和低风险协商。谁促成连接、各方采取了什么行动以及结果如何，继续回到相关个人拥有的上下文。

# 三、始终保持的产品规则

- 单个用户可以独立获得价值，不以对方安装 connectto 为前提。
- Connection 记录一次真实连接，Living Profile 保存私人上下文，Connection Card 只表达当前对象和目的需要的内容。
- 本人表达、介绍人判断、公开事实和 AI 整理始终保留归属。
- 私人关系默认私密，只披露当前行动需要且获得许可的信息。
- AI 可以发现、解释和准备；介绍、发送、敏感披露和重要承诺由本人确认。
- 接受、拒绝、交流与现实结果都回到人物理解和后续判断。
- 用户能够查看来源和适用范围，并能更正、删除、导出、授权、撤销和审计。
- 真实交流开始后，connectto 将表达和关系交还本人。
