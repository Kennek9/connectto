## Timeline

| 时间 | connectto | 为什么 |
| --- | --- | --- |
| 2026.08—10 | 冻结第一阶段完整产品范围，完成端到端原型与技术架构。 | 第一阶段按同一套个人关系 Agent 设计；研发顺序不拆分用户获得的产品范围。 |
| 2026.11—12 | 开发可使用版本，小范围内部测试输入、关系理解、Connector、Connection 与结果回流。 | 确认两类入口都能进入同一闭环，并在手机端完成主要行为。 |
| 2027.01—02 | 邀请创业者和独立 BD 封闭测试，完成第一轮完整产品迭代。 | 同时观察即时价值、重复使用、主动建议、真实行动和下一次连接。 |
| 2027.03 | 继续打磨，整理产品演示、真实案例和使用数据。 | 低调接触少量投资人，先获得反馈和建立关系，不正式融资。 |
| 2027.04—05 | 扩大测试，解决最影响重复使用的问题。 | 同时完成现公司产品上线后的完整周期，准备 reference 和离职判断。 |
| 2027.05—06 | 验证成立后全职投入，进入公开 Beta 或扩大邀请。 | 此时再正式融资，已经有产品、用户证据和完整的个人经历。 |

## 离职与正式融资的判断

- 有用户主动重复使用，而不只是表示喜欢。
- 至少一位用户完整发生“输入或表达当前事项—理解人物与关系—采纳行动—结果回流—再次使用”。
- 现公司产品已完成上线、交付和一次重要迭代，有人能具体证明自己的贡献。
- 已确认个人现金储备，以及保密、知识产权和竞业边界。

如果到 2027 年 5 月仍没有真实使用信号，就继续验证，不因为日期到了而强行离职。
